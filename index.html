Agent Eval Demo — Retrieval & Generation Evaluation

An interactive demonstration of the evaluation methodology I use as a Senior SDET: retrieval and generation eval datasets, deterministic checks, independent semantic review, input decontamination, and dataset version freezing.

All sample data on this page is synthetic — invented for this demonstration. The real datasets were built from internal archived requirements and are not published here.

How the methodology fits together

Two datasets, built from archived requirements:

  • Retrieval eval — a task is a requirement; its gold answers are existing test cases, recalled and confirmed on the spot. Score: how many gold answers the retriever finds (recall), and how many tasks are fully covered (exact match).
  • Generation eval — a task is a requirement design; its gold answers are the test cases finally committed for that requirement. A generated case is checked with deterministic file checks and an independent semantic review.

Both datasets go through the same hygiene steps before any run: input decontamination leakage checks version freeze

Scope of this demo. Dataset construction, deterministic checks, semantic review, decontamination, and versioning. Out of scope here: automated judge rubrics, pass thresholds, and CI eval gates — those are not part of this demo.

Real-world shape, for scale: in production I built a retrieval set of ~20 tasks / ~100 gold answers and a generation set of ~10 tasks / ~40 gold answers. This page uses a 6-task synthetic subset so the pieces can be run in the browser.

3 · Input decontamination & leakage check

Before a requirement enters a dataset, its input is stripped of answer IDs and checked for leakage: if the input itself names a gold answer, the task is contaminated and must be fixed or dropped. Try it — paste any text and check it against the synthetic gold set (TC-101 … TC-116).


4 · Dataset version freeze

A dataset version is frozen once it is used for a run, so results stay reproducible. Changes go into the next draft version instead of mutating the frozen one.
